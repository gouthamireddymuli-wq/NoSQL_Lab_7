Lab 16: Polyglot Persistence — MongoDB, Neo4j & Cassandra

Integrating Document (MongoDB), Graph (Neo4j), and Wide-Column (Cassandra) database paradigms into a unified CTI pipeline

Student: M Gouthami (24BTRCL130)

1. The Tri-Engine CTI Polyglot Architecture

MongoDB (Document)
PRIMARY INTELLIGENCE REPOSITORY

Stores complex STIX 2.1 JSON threat indicators, rich analyst reports, virus scan engine outputs, and metadata indexes. Flexible schemas adapt instantly to new malware properties.

Neo4j (Graph)
MULTI-HOP ATTRIBUTION ENGINE

Maps relational connections: (:ThreatActor)-[:OPERATES]->(:Infrastructure)-[:DEPLOYED]->(:Malware). Cypher graph queries detect shared infrastructure across campaigns in < 5 ms.

Cassandra (Wide-Column)
HIGH-THROUGHPUT LOG INGESTION

Sustains 100,000+ writes/sec of raw firewall flow records, DNS lookups, and honeypot connection logs with linear scaling and LSM-tree append performance.

2. Hybrid Query Dispatcher Implementation 

class PolyglotThreatIntelligenceService:
    def __init__(self, mongo_client, neo4j_driver, cassandra_session):
        self.mongo = mongo_client.cti_platform
        self.neo4j = neo4j_driver
        self.cassandra = cassandra_session

    def investigate_indicator(self, observable_value):
        # 1. Fetch rich document metadata from MongoDB
        ioc_doc = self.mongo.indicators.find_one({"value": observable_value})
        
        # 2. Graph 2-hop infrastructure traversal in Neo4j
        with self.neo4j.session() as session:
            graph_result = session.run("""
                MATCH (i:Indicator {value: $val})-[*1..2]-(actor:ThreatActor)
                RETURN actor.name AS actor, labels(i) AS type
            """, val=observable_value)
            
        # 3. Time-slice last 24h raw sightings from Cassandra
        recent_flows = self.cassandra.execute("""
            SELECT timestamp, src_ip, dst_port, bytes_transferred
            FROM network_flows WHERE dst_ip = %s AND date = toDate(now())
        """, (observable_value,))

        return {"metadata": ioc_doc, "attribution": graph_result.data(), "recent_sightings": list(recent_flows)}
