1. PyMongo Connection Pooling & Lifecycle Management

Creating a new TCP socket connection for every incoming API request creates significant thread contention and socket exhaustion. MongoClient maintains an internal connection pool (default maxPoolSize=100) that automatically recycles open connections across worker threads.

Thread-Safe Singleton Client

from pymongo import MongoClient

# Shared singleton instance
client = MongoClient(
    "mongodb://localhost:27017/",
    maxPoolSize=50,
    minPoolSize=10,
    serverSelectionTimeoutMS=5000
)
db = client["cti_platform"]

Native BSON Data Types

  • ObjectId: 12-byte unique identifier (4-byte timestamp, 5-byte random, 3-byte counter).
  • datetime.datetime: Stored with millisecond precision in UTC epoch.
  • Double / Decimal128: Exact precision for metrics and risk scoring.
  • Embedded BSON Documents: Nested objects with full index support.
