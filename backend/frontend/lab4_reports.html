1. Advanced Querying & Array Manipulation Operators

Real-world threat queries require filtering across nested observable arrays and performing idempotent upserts so that re-ingesting external threat intelligence feeds never generates duplicate records.

Advanced Query Operators

  • $elemMatch: Matches documents containing an array element satisfying ALL specified conditions simultaneously.
  • $in / $nin: Set membership validation for target platforms and threat actors.
  • $regex: Case-insensitive search across CVE vulnerability descriptions and threat actor aliases.
  • $exists / $type: Polymorphic schema inspection for legacy vs upgraded indicators.

Array Modifiers & Idempotency

  • $addToSet: Adds unique elements to an array only if they do not already exist (prevents duplicate IOCs).
  • $push with $slice: Keeps only the most recent N telemetry events (e.g., last 100 pings).
  • upsert=True: Atomically inserts a new record if no matching filter is found; otherwise updates existing.
  • BulkWriteOperation: Batches 10,000+ operations into a single network socket call.

2. High-Throughput Bulk Upsert Pipeline (PyMongo) 

from pymongo import UpdateOne

operations = [
    UpdateOne(
        {"value": item["value"], "type": item["type"]},
        {
            "$set": {"last_seen": item["timestamp"], "confidence": item["confidence"]},
            "$addToSet": {"tags": {"$each": item["tags"]}}
        },
        upsert=True
    )
    for item in incoming_feed_batch
]

result = db.indicators.bulk_write(operations, ordered=False)
print(f"Matched: {result.matched_count}, Upserted: {len(result.upserted_ids)}")
