1. Multi-Tenant Architectural Patterns

Strategy Isolation Level Resource Overhead Max Tenants Supported CTI Platform Decision
Database-per-Tenant High (Physical) High (file handles, index bloat) ~100–300 Reserved for Enterprise VIP / Government Tier
Collection-per-Tenant Medium Medium (namespace limits) ~500 Not recommended due to WiredTiger metadata overhead
Shared Collection + Tenant Guard High (Logical) Minimal 10,000+ RECOMMENDED: Every document has tenant_id with compound index { tenant_id: 1, type: 1 }

2. Python Tenant Guard Query Interceptor 

class TenantGuardCollection:
    def __init__(self, collection, tenant_id):
        self._col = collection
        self.tenant_id = tenant_id

    def find(self, query=None, *args, **kwargs):
        # Automatically inject tenant boundary filter
        scoped_query = query.copy() if query else {}
        scoped_query["tenant_id"] = self.tenant_id
        return self._col.find(scoped_query, *args, **kwargs)

    def insert_one(self, doc, *args, **kwargs):
        # Enforce tenant_id stamping on every write
        doc["tenant_id"] = self.tenant_id
        return self._col.insert_one(doc, *args, **kwargs)
