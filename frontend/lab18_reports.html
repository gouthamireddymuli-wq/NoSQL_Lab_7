2. Executive Production Architectural Decision

Decision: For an enterprise Cyber Threat Intelligence platform operating at scale, the recommended production architecture is a Primary Document Store (MongoDB) with a Graph Auxiliary (Neo4j).

  • MongoDB as Primary Core: Handles 95% of all traffic: threat indicator ingestion, SIEM API lookups, document size control (Lab 7), replica set quorum failovers (Lab 8 & 9), ACID transactions (Lab 10), and AI-native vector search (Lab 17).
  • Neo4j as Graph Accelerator: Subscribed via MongoDB Change Streams (Oplog) to asynchronously maintain relationship edges between threat actors, campaigns, and IP ranges without slowing down primary writes.
  • TCO Impact: Yields a 38% lower Total Cost of Ownership and eliminates brittle relational join migrations.
