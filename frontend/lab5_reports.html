1. The Multi-Stage Aggregation Pipeline Architecture

MongoDB's aggregation framework models data transformations as an assembly line. Documents enter through stage 1 and each stage transforms the stream before passing it to subsequent stages, enabling analytical queries without transporting raw datasets over the network.

Essential Pipeline Stages

  • $match: Filters the working set early to utilize available indexes and reduce memory consumption.
  • $lookup: Performs left outer equijoins to correlate indicators with threat actor dossiers.
  • $unwind: Deconstructs an array field from the input documents to output a document for each element.
  • $group: Groups documents by specified identifier expression and applies accumulator expressions.

Parallel Analytics via $facet

$facet processes multiple aggregation sub-pipelines in parallel within a single pipeline stage on the same input documents, returning multiple aggregated views (e.g. platform breakdown + severity breakdown + top 5 actors) in a single database round-trip.

allowDiskUse=True bypasses 100 MB RAM stage cap

2. Threat Actor Correlation Pipeline with $lookup & $facet 

pipeline = [
    {"$match": {"status": "Active"}},
    {"$lookup": {
        "from": "threat_actors",
        "localField": "actor_id",
        "foreignField": "_id",
        "as": "actor_dossier"
    }},
    {"$unwind": "$actor_dossier"},
    {"$facet": {
        "by_platform": [{"$group": {"_id": "$platform", "count": {"$sum": 1}}}],
        "by_severity": [{"$group": {"_id": "$severity", "avg_confidence": {"$avg": "$confidence"}}}],
        "top_actors": [{"$group": {"_id": "$actor_dossier.name", "total_iocs": {"$sum": 1}}}, {"$sort": {"total_iocs": -1}}, {"$limit": 5}]
    }}
]
analytics_results = db.indicators.aggregate(pipeline, allowDiskUse=True)
