1. The ESR (Equality, Sort, Range) Golden Rule

Without indexes, MongoDB performs a COLLSCAN (Collection Scan), reading every document from disk into memory. The ESR Rule guarantees an optimal compound index structure that eliminates in-memory sorting and minimizes index key examinations:

[E] Equality First

Exact matches (e.g. platform: "Linux", status: "Active") narrow down the search space to a tight subset of index leaves.

[S] Sort Second

Matches the requested query order (e.g. timestamp: -1), allowing MongoDB to traverse index keys directly without memory sort (SORT stage eliminated).

[R] Range Last

Inequality filters (e.g. confidence: {"$gte": 80}). Placing range before sort breaks index-assisted sorting.
